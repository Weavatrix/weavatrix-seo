Search-architecture **gap detection**. Opportunities are work to *build*, not the current error list.

```rust
use weavatrix_seo_opportunity::{opportunities, rank};

let items = rank(opportunities(&inventory, &architecture));
```

Demand stays `UNMEASURED` until GSC (or an equivalent search-performance import) is connected. Unknown confidence/risk is a ranking bucket, not 100/0.

CLI: `weavatrix-seo opportunities`. MCP: `seo_opportunities`.

```toml
[dependencies]
weavatrix-seo-opportunity = "0.6.2"
```
